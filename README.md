# RESERVASI KOST

Website Reservasi Kost merupakan aplikasi berbasis web yang dikembangkan menggunakan PHP Native dan Supabase PostgreSQL. Aplikasi ini dibuat untuk memudahkan pengguna melihat informasi kamar kost dan melakukan reservasi secara online.

## Teknologi yang Digunakan
- PHP Native
- HTML
- CSS
- JavaScript
- Supabase PostgreSQL
- XAMPP
- Visual Studio Code

## Fitur Website
1. Registrasi akun pengguna
2. Login pengguna dan admin
3. Menampilkan daftar kamar kost
4. Melihat detail kamar
5. Melakukan reservasi kamar
6. Melihat riwayat reservasi
7. Dashboard admin
8. Pengelolaan data kamar dan reservasi

## Database
Website ini menggunakan Supabase PostgreSQL sebagai sistem basis data.

File `database.sql` berisi struktur tabel yang digunakan dalam aplikasi.

Konfigurasi koneksi database disimpan secara lokal pada `config.php` dan tidak disertakan dalam repository publik demi keamanan.

## Cara Menjalankan Website
1. Instal dan jalankan XAMPP.
2. Letakkan folder website di dalam direktori `htdocs`.
3. Aktifkan Apache melalui XAMPP Control Panel.
4. Atur koneksi Supabase pada file `config.php`.
5. Buka browser dan akses alamat:

   `http://localhost/reservasi-kost/reservasi-kost/kost/index.php`
